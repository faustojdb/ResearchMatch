# Sesion 15 — Commands + Skills para Claude Code Plugin

**Fecha:** 2026-02-17
**Version:** 2.8.0-contracts (sin cambio de version)
**Objetivo:** Agregar slash commands y skill al plugin ZIP para que Claude Code pueda invocar los 24 MCP tools via comandos guiados

---

## Contexto

Research Match v2.8.0 funciona como DXT en Claude Desktop (24 tools visibles en permisos), pero Claude no puede invocarlos facilmente en conversacion sin guia. El formato **Claude Code Plugin** soporta `commands/` (slash commands) y `skills/` (habilidades auto-activables) que proporcionan flujos guiados sobre los MCP tools.

| `skills/research-match/SKILL.md` | Auto-activable | Se activa cuando el usuario menciona "research matching", "originality scoring", "find collaborators", etc. Documenta flujo completo, OT/OFC, semaforo bilateral, privacy model |

Archivo de configuracion MCP en la raiz del proyecto para que Claude Code detecte el servidor automaticamente al iniciar sesion desde este directorio.

```json
      "command": "uv",
      "args": ["--directory", ".", "run", "research-match"],
      "env": { "RESEARCH_MATCH_DB": "research_match.db" }
    }
  }
}
```

## Formato de Commands

Cada command usa YAML frontmatter con:
- `name`: nombre del slash command (ej: `rm-search`)
- `description`: descripcion para el usuario
- `argument-hint`: hint de argumentos (ej: `[search query]`)
- `disable-model-invocation: true`: solo se activa via slash command explicito
- `allowed-tools`: lista de tools MCP con formato `mcp__research-match__research_match_<nombre>`

El contenido markdown guia a Claude paso a paso: que preguntar al usuario, que tools invocar, como presentar resultados.

## Formato de Skill

Similar a commands pero con:
- `user-invocable: false`: no aparece en menu de slash commands
- Se activa automaticamente cuando Claude detecta keywords en la conversacion
- Documenta todos los tool groups, conceptos (OT/OFC, semaforo, privacy levels), y flujos
