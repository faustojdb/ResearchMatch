## Errores de Instalación en Claude Desktop

### Error 1: `"url"` en mcpServers crashea Claude Desktop
```json
{"mcpServers": {"research_match": {"url": "http://localhost:8000/mcp/"}}}
```
**Resultado**: "Claude Desktop failed to Launch"
**Log** (`launch-failure.err`): `TypeError: Cannot read properties of undefined (reading 'value')`
**Causa**: La versión Windows Store (1.1.3189.0) no soporta campo `url` en mcpServers.

### Error 2: `"command"/"args"` en mcpServers — ignorado silenciosamente
```json
{"mcpServers": {"research_match": {"command": "wsl.exe", "args": ["bash", "-lc", "..."]}}}
```
**Resultado**: Claude Desktop abre bien pero NO muestra las tools de research_match.
**Causa**: Esta versión solo usa el sistema de **extensions** (no mcpServers del config).

### Error 3: Extension manual inyectada — ignorada
Creamos manualmente:
- `Claude Extensions/ant.dir.faustojdb.research-match/manifest.json`
- Entry en `extensions-installations.json`
- `Claude Extensions Settings/ant.dir.faustojdb.research-match.json` con isEnabled=true

**Resultado**: No aparece en la UI.
**Causa**: Extensions pasan por API `can_install` de Anthropic que valida contra registry.

### Error 4: "Agregar desde URL" con localhost
URL: `http://localhost:8000/mcp/`
**Resultado**: "El acceso de red a "localhost" está bloqueado por la configuración de salida."

### Error 5: "Agregar desde URL" con cloudflare tunnel
URL: `https://shoe-tone-schema-trustee.trycloudflare.com/mcp/`
**Resultado**: "El acceso de red a "shoe-tone-schema-trustee.trycloudflare.com" está bloqueado por la configuración de salida."

### Error 6: "Agregar desde URL" desde chat normal (no Cowork)
URL: `http://localhost:8000/mcp/`
**Resultado**: No funciona tampoco.

## Conclusión
La ÚNICA forma de instalar un MCP server en Claude Desktop Windows Store es:
1. Publicarlo como **extension en el marketplace de GitHub**
2. O que Anthropic lo apruebe en su registry
