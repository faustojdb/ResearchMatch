### 2.4 Analisis Profundo de Repos

**MastersThesis (Relevancia ALTA):**
- Tesis UCM 2018, Solidity contracts + IPFS
- Reputacion con exponential smoothing (alpha=0.2)
- Ratings multi-stakeholder, penalidades por deadline
- Analisis privacy tradeoffs (blind vs open vs double-blind)
- Limitacion: Solidity 0.4.x, no production-ready

**fhe-ml (Relevancia MEDIA-ALTA):**
- TenSEAL (CKKS scheme), 128-bit security
- 0% perdida de accuracy (86.13% plain = 86.13% encrypted)
- 200x slowdown — prohibitivo para tiempo real
- Max ~6 multiplicaciones antes de ruido destructivo
- Sigmoid approximation: `-0.004x^3 + 0.197x + 0.5`

**claude-skills-mcp (Relevancia ALTA):**
- Two-package architecture (frontend ligero + backend pesado)
- Tool descriptions ultra-detalladas con flujo y ejemplos
- Search semantico con sentence-transformers (local, sin API)
- Health endpoint, background loading, auto-update
- 15+ archivos de tests, thread-safe state management

**Researcher-Tool-AI (Relevancia BAJA):**
- Frontend React que delega todo a Google Gemini API
- NO tiene algoritmos propios de originalidad
- Solo util por patrones de UI/UX y parallel execution

### 2.5 Implementacion P0 (3 tareas completadas)

#### P0.1 — Tool Descriptions Mejoradas

#### P0.2 — Health Endpoint
- `GET /health` implementado via `mcp.custom_route()`
- Reporta: version, DB path, stats (users/commits/matches/teams/pending_requests/ratings)
- Embedding model info incluido
- Testeado y funcionando en `localhost:8001/health`

#### P0.3 — Sentence-Transformers Integration
- `EmbeddingEngine` clase nueva: lazy-load, thread-safe (`threading.Lock`), Jaccard fallback
- Modelo: `all-MiniLM-L6-v2` (384 dims, ~90MB)
- Integrado en: `OriginalityEvaluator._text_similarity()`, `._commit_similarity()`, `MatchingEngine._base_similarity()`
- Dependencias: `sentence-transformers>=3.0.0`, `numpy`
